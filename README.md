# Eduardo — Fotografia, vídeo e produção audiovisual

Base inicial do portfólio de **Eduardo**, mantida em [eduardodinizpro/Eduardo](https://github.com/eduardodinizpro/Eduardo).

**Status:** estrutura pronta para personalização. Ainda não há trabalhos, imagens, biografia ou contatos cadastrados. Todos os campos `[PREENCHER: ...]` e estados “A preencher” indicam conteúdo pendente, não informações profissionais confirmadas.

## Começar

1. Baixe ou clone este repositório.
2. Abra `site/index.html` no navegador. Não há instalação, compilação ou dependências.
3. Edite os textos em `site/index.html` e o visual em `site/assets/css/styles.css`.
4. Adicione imagens otimizadas em `site/assets/images/`, com descrições alternativas.
5. Substitua os espaços reservados por projetos reais e revise [as pendências](docs/PENDENCIAS.md).

## Escopo da base

O site contém navegação, apresentação, áreas de atuação, espaços para projetos e seção de contato. Funciona sem JavaScript e sem serviços externos. O contato está indicado como pendente: não há formulário nem envio de mensagens.

As fichas em `portfolio/` são documentação; editar uma ficha **não atualiza automaticamente o site**. Copie os dados revisados para o HTML.
