# Manutenção

- Escreva documentação e conteúdo em português.
- Use nomes de arquivo em minúsculas, sem espaços ou acentos.
- Documente trabalhos com `templates/PROJETO.md`.
- Não publique dados privados nem arquivos brutos.
- Preserve campos pendentes até obter informações confirmadas.
- Faça mudanças pequenas, com mensagens de commit claras.
- Ao alterar o site, abra `site/index.html` e confira navegação, links, teclado e largura de celular.
- Antes de enviar, revise `git diff` e `git status` para conferir os arquivos incluídos.

Esta base não exige ferramentas de compilação nem possui testes automatizados.
